# ADR-0002: First real-user module is CBT/Study

Status: ACCEPTED (2026-08)
Supersedes: PRD v0.4 suggestion of School-first sequencing.

## Context
renancecbt.vercel.app already carries partial usage/traction. The School
suite has heavier compliance/reporting needs and zero existing traffic.

## Decision
Phase 2 ships the CBT/Study MVP as the platform's first real user surface.
School Suite follows in Phase 3 with its results/PIN/fee loop.

## Consequences
- earlier validation of Core identity, payments plumbing and store presence;
- existing CBT users provide immediate feedback instead of cold start;
- School features wait one phase; PRD ordering is consciously overridden.
