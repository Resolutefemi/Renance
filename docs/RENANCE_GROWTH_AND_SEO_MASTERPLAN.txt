4. RENANCE'S PRESENT TECHNICAL STATE: THE ASSETS & THE PROBLEM
================================================================================
OUR EXISTING ASSETS (ALREADY IN THE REPOSITORY):
- Question Vault: 207,172 banked past questions in data/questions/ (JAMB 1978–2025, 
  WAEC, NECO, Post-UTME, University Modules).
- Manifest: 681 active packs cataloged in data/manifest.json.
- Curriculum: Full NERDC schemes of work from Primary 1 to SSS 3 in data/school-schemes/.
- University Desk: 157 Nigerian universities and 521 accredited courses in data/university/.
- Web Engine: Next.js 15 App Router (apps/web) with static export (output: 'export').
  Baseline build test confirmed: 1,455 static routes compile in 21.6 seconds!

THE PRESENT PROBLEM (THE "WALLED GARDEN" DEFECT):
Currently, all 207,172 questions are rendered client-side via JavaScript loaders 
inside /exams/[code]. 
- When Googlebot visits /exams/jamb-physics-bank, it sees an empty JavaScript shell.
- Googlebot does not execute multi-step user clicks to select years or start exams.
- Result: We own 207,172 questions, but Google has indexed ZERO of them as search 
  results. We are invisible for "JAMB 2024 Physics past questions".

Target Route Structure:

- /exams/neco/chemistry/2022/
- /curriculum/ss2/biology/first-term/

WHAT EACH PAGE CONTAINS:
1. High-Yield Question Previews:

   - Shows question stem, options, verified correct answer, and step-by-step 
     worked explanation.
   - Renders mathematical and chemical formulas using KaTeX LaTeX notation.

2. Google Quiz Structured Data (Position 0 Rich Snippets):

     Google Search before the student even clicks a link.

3. Generative Engine Optimization (GEO):
   - Tags each question with statutory NERDC curriculum themes.
   - When students ask ChatGPT, Perplexity, or Gemini: "Solve Question 12 from 
     JAMB 2024 Physics", the AI extracts our structured explanation and cites:
     "Source: Renance (renance.app)".

6. ZERO-RISK ARCHITECTURE: WHY THIS CANNOT BREAK OR DELAY THE MOBILE APP
================================================================================
As Cyber Security Lead (Clinton) and CTO (Femi), systems reliability and isolation 
are your top priorities. Here is the strict engineering guarantee:

1. 100% Codebase Decoupling:
   - The Flutter mobile application (apps/mobile) is entirely isolated.
   - It compiles directly into an Android APK / AAB bundle using its embedded 
     SQLite database and communicates with apps/study-api.
   - The SEO pages live exclusively in apps/web. The mobile codebase is completely 
     untouched.

2. 100% Additive Web Routes:
   - Existing routes (/exams/[code], /dashboard, /school, /school/check, /login) 
     remain unchanged.
   - The new routes are purely additive public landing hubs.

3. Zero Database Overload:
   - All programmatic pages are pre-rendered into static HTML at build time 
     (output: 'export').
   - When 50,000 students hit these pages simultaneously, they hit CDN cache. 
     Zero database queries, zero server CPU spikes, zero crash risk.
