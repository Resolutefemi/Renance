# Exam Bank Desk Guide

The exam desk at `/school/exams` holds two tabs: the question pool and
the published papers. Questions are stored per subject, per term, per
session, tagged with a class band.

## Growing the pool

1. Pick a subject (and a band filter if you want).
2. Fill the Add a question card: the question text, two to six
   options, the correct option marked with the radio, and an optional
   explanation for after the marking.
3. Add to bank files it into the pool. The bank also accepts the house
   starter bank: Pour starter bank adds the original Renance question
   set for every subject the school runs. It is safe to re-run.

## Publishing and printing a paper

1. Switch to Published papers and fill the publish card: class,
   subject, how many questions and the sitting duration.
2. Publish pins the paper. Republishing the same class, subject, term
   and session updates it instead of duplicating.
3. Open assembles the paper: it draws that many questions from the
   pool behind the class's band. Print opens the browser dialog for a
   clean A4 sheet.

## House rules

- Questions added from the portal are tagged school-original; the
  starter bank is tagged renance-original. Nothing is copied from
  third parties.
- Text is stored clean: any `--` typed by mistake collapses to a
  single dash before the question is saved.
