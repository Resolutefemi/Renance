# Results Desk Guide

Results live at `/school/results`. Management sees the whole school;
teachers fill only the class+subject cells assigned to them.

## The filling rhythm

1. Pick class, term and session. The grid opens one row per student,
   one column per subject the class offers.
2. Fill CA1, CA2 and Exam per subject. Totals, grades and remarks
   compute as you save each cell.
3. When the class is complete, Finalize and issue PINs seals the term:
   positions, class averages and the report remarks are computed, and
   every student receives a private 6-digit PIN.

## The report card

Open a student to see the full report card with the school logo and
name stamped. Download report card (PDF) produces the printable
A4 sheet parents recognise.

## The PIN checker

The PIN is the student's credential. Anyone holding it can check that
result at `/school/check` without signing in: enter the PIN, the term
and the session, and the finalized report card appears with a PDF
download. A PIN only ever opens its own term and session.

## Order of operations that avoids pain

Set up the school logo and class subjects first, enroll students with
their subject tracks, then fill. Finalize locks the numbers; a
finalized term is a print-and-distribute job, not an editing session.
