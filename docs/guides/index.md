# School Portal Guides

Desk-by-desk walkthroughs for the For Schools workspace. Every guide
assumes you signed in through the For Schools switch and landed on the
portal home.

| Desk | Guide | One line |
| --- | --- | --- |
| School Setup | [setup.md](setup.md) | Identity, curriculum install, class subjects. |
| Syllabus & Notes | [syllabus.md](syllabus.md) | Terms, schemes, topics, notes, PDFs. |
| Attendance | [attendance.md](attendance.md) | Daily roster, kiosk, summaries, CSV. |
| Timetable | [timetable.md](timetable.md) | The weekly grid per class. |
| Exam Bank | [exams.md](exams.md) | Question pool, starter pour, papers. |
| Students | [students.md](students.md) | Enrollment, details, subject tracks. |
| Teachers | [teachers.md](teachers.md) | Staff accounts and assignments. |
| Results | [results.md](results.md) | Score cells, finalize, PINs, report cards. |
| Fees | [fees.md](fees.md) | Charges, receipts, balances. |
| ID Cards | [idcards.md](idcards.md) | Serials, batch issue, print sheet. |

Roles: everything works for management; teachers see the academic
desks (syllabus, attendance, timetable, exams, their results cells).
Feescopes, ID cards and enrollment stay management-only.
